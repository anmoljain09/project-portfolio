
# 02. Summer Training

*Brain Mentors Pvt. Ltd. | In Collaboration with BVCOE*  
*June 2025 – July 2025*

---

### 📌 Overview

Completed a five-week in-house MERN Stack and AI training program conducted by Brain Mentors Pvt. Ltd. in collaboration with Bharati Vidyapeeth's College of Engineering.

As part of the training, developed a Task Manager Web Application to gain practical experience in full-stack development.

### 🎯 Objective & Approach

The objective was to strengthen practical web development skills through hands-on implementation of a MERN Stack application.

Followed an MVC-based backend architecture and implemented JWT-based authentication for user access and task management.

### ⚙️ Work & Responsibilities

- Developed a Task Manager Web Application using the MERN Stack.
- Implemented CRUD operations for task creation, viewing, updating, and deletion.
- Integrated JWT-based user authentication.
- Structured backend functionality using MVC architecture.
- Connected frontend components with backend APIs and MongoDB.

### 🛠️ Technologies & Tools

- **Languages:** JavaScript, HTML, CSS
- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Authentication:** JWT
- **Tools:** Git, GitHub, VS Code

### 🧠 Learning & Challenges

- Gained practical experience with frontend-backend integration.
- Understood REST API development and database operations.
- Explored authentication mechanisms and MVC architecture.
- Strengthened understanding of full-stack development workflows.

### 📊 Outcomes & Achievements

- Successfully completed the five-week MERN Stack and AI training program.
- Secured **88/100** in the training assessment.
- Developed a functional Task Manager application with authentication and task management features.
