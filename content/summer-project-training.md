
# 01. Summer Project Training

*Project Work Under Dr. Jolly Parikh, BVCOE*  
*July 2026 – September 2026*

---

### 📌 Overview

Developed an AI-powered Chat Application under the guidance of Dr. Jolly Parikh, Associate Professor, Department of Computer Science and Engineering, BVCOE.

The application integrates MERN Stack technologies with a Python-based AI service using a microservices architecture.

### 🎯 Objective & Approach

The objective was to understand the integration of AI capabilities into a full-stack web application.

Designed the application around four independent components:

- API Gateway
- Authentication Service
- Chat Service
- AI Agent Service

### ⚙️ Work & Responsibilities

- Developed the frontend using React.js, Vite, React Router, and Axios.
- Worked with an API Gateway built using Node.js and Express.js.
- Implemented Google Sign-In using Firebase Authentication and Firebase Admin SDK.
- Integrated Redis Cloud for session management and httpOnly cookies.
- Implemented conversation and message management using MongoDB and Mongoose.
- Developed a Python-based AI Agent Service using FastAPI and Pydantic.
- Integrated Groq API with the Llama 3.3 70B model for AI-generated responses.

### 🛠️ Technologies & Tools

- **Languages:** JavaScript, Python
- **Frontend:** React.js, Vite
- **Backend:** Node.js, Express.js, FastAPI
- **Database:** MongoDB, Redis Cloud
- **Authentication:** Firebase
- **AI Integration:** Groq API, Llama 3.3 70B
- **Tools:** Git, GitHub, Axios

### 🧠 Learning & Challenges

- Understood microservices architecture and inter-service communication.
- Gained experience with API Gateway routing and authentication workflows.
- Learned session management using Redis and persistent storage using MongoDB.
- Explored integration of external Large Language Models into web applications.

### 📊 Outcomes & Achievements

- Successfully developed an AI-powered Chat Application.
- Implemented separate authentication, chat, and AI services.
- Integrated Google Sign-In, Redis, MongoDB, and Groq LLM.
- Completed manual testing of seven principal test cases.
- Prepared and submitted the project report under the guidance of Dr. Jolly Parikh.
