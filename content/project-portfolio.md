
# P-01. Project Portfolio

*Self-Initiated Web Development Project | 2026*

---

### 📌 Overview

Developed a personal portfolio website inspired by exploring an existing open-source documentation project.

Instead of relying entirely on conventional tutorials, explored a real-world codebase to understand its architecture and template-rendering approach.

### 🎯 Objective & Approach

The objective was to build a modular and content-driven portfolio by adapting an existing template-rendering concept.

Used separate Markdown files to organize portfolio content and integrated them with a Node.js and Express.js application.

### ⚙️ Work & Responsibilities

- Explored an existing open-source GitHub repository and studied its architecture.
- Understood its content organization and template-rendering mechanism.
- Created separate Markdown files such as `start.md`, `experience.md`, and `end.md`.
- Adapted the rendering approach to display different portfolio sections.
- Integrated Markdown-based content with Node.js and Express.js.

### 🛠️ Technologies & Tools

- **Language:** JavaScript
- **Backend:** Node.js, Express.js
- **Content Format:** Markdown
- **Platform:** GitHub
- **Tools:** VS Code, Git

### 🧠 Learning & Challenges

- Learned to explore and understand an existing codebase independently.
- Gained practical experience with template rendering.
- Understood modular content organization using Markdown.
- Strengthened independent learning and problem-solving skills.

### 📊 Outcomes & Achievements

- Developed a personal portfolio website using a template-rendering approach.
- Implemented Markdown-based content management.
- Organized portfolio sections into separate, maintainable files.
- Gained experience in adapting existing development concepts to a new project.
