## 01. Summer Project Training

*Project Work Under Dr. Jolly Parikh, BVCOE*  
*July 2026 – September 2026*

### 📌 Overview

Developed an AI-powered Chat Application as a guided summer project under the supervision of Dr. Jolly Parikh, Associate Professor, Department of Computer Science and Engineering, BVCOE.

The application enables users to interact with an AI model through conversational interfaces. It combines MERN Stack technologies with a Python-based AI service, following a microservices architecture to separate authentication, chat management, and AI processing.

### 🎯 Objective & Approach

The primary objective was to understand how AI capabilities can be integrated into a full-stack web application using independently structured backend services.

Adopted a microservices-based architecture consisting of four major components: API Gateway, Auth Service, Chat Service, and AI Agent Service.

Integrated Firebase Authentication for Google Sign-In, Redis Cloud for session management, MongoDB for persistent chat storage, and Groq API for AI-generated responses.

### ⚙️ Work & Responsibilities

- Developed the frontend using React.js and Vite, with React Router for navigation and Axios for API communication.
- Worked with an API Gateway built using Node.js, Express.js, and express-http-proxy to route requests between backend services.
- Implemented authentication using Firebase Admin SDK and Google Sign-In.
- Integrated Redis Cloud for session management and httpOnly cookies for session handling.
- Developed conversation and message management functionality using MongoDB and Mongoose.
- Built a Python-based AI Agent Service using FastAPI and Pydantic.
- Integrated Groq API to generate AI responses using the Llama 3.3 70B model.

### 🛠️ Technologies & Tools

- **Languages:** JavaScript, Python
- **Frameworks / Libraries:** React.js, Vite, Node.js, Express.js, FastAPI, Pydantic
- **Database / Platforms:** MongoDB, Redis Cloud, Firebase, Groq API
- **Tools:** Git, GitHub, Axios, React Router, Firebase Admin SDK

### 🧠 Challenges & Learning

Gained practical experience in connecting independently developed services and managing communication across a distributed application architecture.

Developed an understanding of API Gateway routing, authentication workflows, session management, persistent data storage, and integration with external Large Language Models (LLMs).

The project strengthened my understanding of how frontend, backend, database, and AI services interact within a distributed application.

### 📊 Outcomes & Achievements

- Successfully developed an AI-powered Chat Application using MERN Stack technologies and Python.
- Implemented a microservices architecture with separate authentication, chat, and AI services.
- Integrated Google Sign-In, Redis-backed session management, MongoDB-based chat storage, and Groq LLM.
- Completed manual testing of seven principal test cases.
- Prepared and submitted the project report under the guidance of Dr. Jolly Parikh.
